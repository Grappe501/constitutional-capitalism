# EIA-861 ownership + reliability bind

- **Ownership:** Form EIA-861 `Sales_Ult_Cust_YYYY.xlsx` (States sheet), Service Type = Bundled, customer counts by Ownership → AR/US IOU / coop / muni shares (2018–2024 in this bind; 2014 `.xls` not parsed here).
- **Reliability:** EIA Electric Power Annual Table 11.4 SAIDI minutes/year by state (2014–2024), built from Form EIA-861 reliability reporting.

Layers are separate from MER generation/production already on `CC-EP-ENERGY-STRUCTURAL-ENDPOINTS-1`. Not prosperity-fund outcomes.

Source: https://www.eia.gov/electricity/data/eia861/ · https://www.eia.gov/electricity/annual/html/epa_11_04.html
