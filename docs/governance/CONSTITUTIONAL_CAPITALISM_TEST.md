# The Constitutional Capitalism Test

Status: proposed defining feature (open decision `CC-DEC-031`)  
Last updated: 2026-08-04  
Canonical register: `data/project/constitutional_capitalism_test.json`

## Purpose

Before any proposed law, regulation, tax, subsidy, or reform is accepted into the Constitutional Capitalism framework, it must answer a standard set of questions.

This shifts debate from:

> “Do I like this policy?”

to:

> “Does this policy satisfy the constitutional principles we’ve adopted?”

It creates a common screen that can be applied consistently to proposals from across the political spectrum.

## The ten questions

1. Does it expand or reduce individual liberty?  
2. Does it broaden or concentrate ownership?  
3. Does it increase or reduce competition?  
4. Does it strengthen or weaken communities?  
5. Does it reward productive value creation?  
6. Does it increase or reduce dependency?  
7. Does it make the next generation more prosperous?  
8. Does it preserve constitutional limits on power?  
9. Does it improve transparency and accountability?  
10. Is there a measurable way to determine whether it worked?

## Application rules

- Apply to every policy pillar and proposal before publication readiness rises.  
- Record answers in policy records or companion worksheets — not slogans.  
- Mixed or uncertain answers are valid; silence is not.  
- A proposal that fails several questions is not automatically banned from discussion, but must not be presented as Constitutional Capitalism-compliant without disclosure.  
- Question 10 should normally cite National Baseline / dashboard indicators or a defined pilot metric.

## Relationship to other systems

| System | Relationship |
|---|---|
| Principles | Test operationalizes principles as a gate |

| National Baseline | Supplies measurability for Q10 |

| Argument layers | Test answers are not evidence; they are discipline |

## Publication discipline

Do not claim the Test is ratified constitutional law. It is a proposed philosophical and policy screen until Steve approves it as a locked project standard.
