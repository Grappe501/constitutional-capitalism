# Chapter Development Workflow

concept → outline → researching → drafting → draft_complete → editing → fact_check → legal_review → final → published

Update chapter front matter and `book_structure.json` together. Keep `chapter_id` stable.

## Evaluation closing block

From `researching` / `drafting` onward, chapters should include the Chapter Evaluation Template:

Success Metrics · Risks · Counterarguments · Pilot Test · Constitutional Questions · Research Still Needed · International Examples · Impact Timeline

See `docs/writing/CHAPTER_EVALUATION_TEMPLATE.md` and `data/project/chapter_evaluation_template.json` (`CC-DEC-032`).

Factual claims link to Book Two (`content/evidence-companion/`). Implementation pathways link to Book Three (`content/implementation-manual/`).
