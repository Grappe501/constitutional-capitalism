# Chapter Evaluation Template

Status: proposed writing standard (open decision `CC-DEC-032`)  
Last updated: 2026-08-04  
Machine register: `data/project/chapter_evaluation_template.json`

## Purpose

Make Constitutional Capitalism **measurable**.

Every developed chapter (and eventually all ~90+ units) should end with a consistent evaluation block. The public book stays readable; the evaluation block forces honesty about success, risk, and evidence gaps.

## Required closing sections

### Success Metrics

How would we know this chapter’s idea worked?

Map to National Baseline indicators when possible.

### Risks

What could go wrong?

### Counterarguments

What would critics say?

### Pilot Test

How could this be tested in one state (or comparable jurisdiction)?

### Constitutional Questions

What constitutional issues arise?

### Research Still Needed

What evidence remains incomplete?

Link claim IDs / Evidence Companion entries.

### International Examples

Has any nation attempted something similar?

No invented examples. If unknown, say so.

### Impact Timeline

Expected effects (labeled as predictions / hypotheses, not proven outcomes):

- 6 months  
- 2 years  
- 5 years  
- 10 years  
- 25 years  

## Workflow placement

Insert this block when a unit leaves `outline` for `researching` / `drafting`.  
Earlier stages may keep a stub checklist in front matter or brief.

See also: `CHAPTER_DEVELOPMENT_WORKFLOW.md`.

## What this changes about the book

The work stops saying only “here is my idea.”

It says:

> Here is a constitutional framework, the evidence supporting it, the uncertainties, the implementation path, and the criteria by which you should judge whether it succeeds.
