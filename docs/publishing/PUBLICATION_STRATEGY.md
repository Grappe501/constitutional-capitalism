# Publication Strategy

Free public web edition first; PDF/EPUB later; print-ready optional. Public site must not overstate completion.

## Data-dense by default (`CC-DEC-104`)

Canonical standard: [`DATA_DENSE_PUBLICATION_STANDARD.md`](./DATA_DENSE_PUBLICATION_STANDARD.md) · `data/project/data_dense_publication_standard.json`.

When reliable data exist, show them where the reader meets the theory. Use progressive disclosure so ordinary readers get clarity and specialists get depth. Every displayed statistic must be traceable; contradictions and honesty labels are required; never decorate rhetoric with persuasive orphan numbers.
