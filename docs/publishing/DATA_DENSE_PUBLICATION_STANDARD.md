# Data-Dense Publication Standard 1.0

**Decision:** `CC-DEC-104`  
**Canonical JSON:** `data/project/data_dense_publication_standard.json`  
**Report:** `reports/CC_DATA_DENSE_PUBLICATION_STANDARD_1_0.md`

## Governing rules

> **When reliable data exist, show them. Do not merely cite them in the background. Put the evidence where the reader encounters the theory.**

> **DATA-DENSE BY DEFAULT.** Every substantive public theory, doctrine, proof, and policy surface should use the maximum amount of relevant, high-quality, comprehensible real-world data available without creating false precision, cherry-picking, or unnecessary visual clutter.

> **Every displayed statistic must be traceable** to a canonical data asset, observation period, geography, definition, and primary source whenever available.

> **Never add a statistic merely because it sounds persuasive.**

## Presentation hierarchy

**Idea → evidence → comparison → implication → uncertainty → source.**

## Progressive disclosure

**First view:** key finding · 3–5 critical numbers · one strong visualization · plain-English explanation.

**Explore the data:** tables, historical series, methodology, comparisons, downloads, provenance, related proof packets.

## Evidence Panel

Every major theory, claim, doctrine, or policy surface should support a reusable Evidence Panel:

- What the data show
- Evidence strength (Direct / Strong / Partial / Weak)
- What supports this
- What challenges it
- What we don’t know
- Last updated
- Explore (table · methodology · sources · proof packet)

## Honesty labels

Use visible labels such as: current data unavailable; Arkansas-specific evidence unavailable; national evidence only; historical observation — current update pending; association, not demonstrated causation; model estimate — not observed data.

## Binding to the data bridge

Pages should eventually reference `metric → observation → dataset → agency → release` via the RedDirt → CC public-statistics bridge rather than orphan hardcoded numbers. Constitutional Capitalism remains a research consumer, not a credential holder.
