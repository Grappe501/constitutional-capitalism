# Evidence Companion (Book Two)

This directory holds human-readable evidence dossiers for factual claims in Book One.

Machine spine:

- `data/research/claim_ledger.json`
- `data/research/source_registry.json`

## Entry pattern

Each dossier should cover:

1. Supporting research  
2. Opposing research  
3. Limitations  
4. Confidence level  
5. Questions remaining  
6. Data sources  

Do not invent citations. Prefer linking claim IDs (`CC-CLAIM-###`) and source IDs.

See `docs/architecture/THREE_BOOK_ARCHITECTURE.md`.
