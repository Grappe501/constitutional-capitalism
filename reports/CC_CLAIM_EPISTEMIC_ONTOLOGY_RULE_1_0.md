# Claim Epistemic Ontology Rule 1.0

**Status:** Active research-integrity rule (not new architecture)  
**Slice:** `CC-PHASE-2.1-APPLY-CHATGPT-CLAIM-GOVERNANCE-DECISIONS-1.0`

## Principle

Do not ask a single `CLAIM` object to perform multiple epistemic jobs.  
Do not repair an unsupported claim by replacing it with a slightly better unsupported claim.

## Classes

| Class | Meaning |
|---|---|
| EMPIRICAL_CLAIM | What evidence indicates is/was true. |
| HISTORICAL_CLAIM | What evidence establishes happened. |
| CAUSAL_CLAIM | Evidence that X materially causes Y. |
| PREDICTION | What we expect may happen. |
| HYPOTHESIS | Proposition deliberately awaiting testing. |
| NORMATIVE_PROPOSITION | What the philosophy says ought to happen. |
| DESIGN_ASSUMPTION | Something a proposed mechanism depends upon. |
