## Verdict

Value Capture and Enterprise are **strategically central** to the public-income design — and still **$0 COUNTABLE NOW**. Existing Arkansas tools (TIF, AEDC incentives, airport/port authorities, conduit industrial bonds, water enterprises) either **pledge cash to project debt**, **give public risk without upside**, or **lack statewide net-cash surveys**. Fail-closed counting stands.

The philosophical distinction remains locked:

> Taxing value created independently ≠ earning a return on value materially created by public capital, public land, public infrastructure, or exclusive public rights.

## Non-negotiable field: `PUBLIC_RISK_AT_RISK`

Every candidate carries a risk/upside alignment test:

- If the public takes meaningful downside risk, it should not automatically receive only taxes while private owners keep all upside.  
- If private capital carries nearly all risk, the state is not entitled to most of the return.

Hard cash-flow schema applied to each candidate:

`capital → financing → ownership/contract → gross → O&M → debt → reserves → net distributable → volatility → downside → legal → state/local split → truly incremental recurring`

## Questions answered

1. **Can Arkansas earn meaningful recurring public income by retaining a share of publicly created value?** In principle yes (participation redesign, ground leases, ports/industrial parks, energy/broadband ownership). In practice, **no countable statewide free cash** cleared this pass.  
2. **Do airports, TIF, and industrial-development bonds already solve this?** No — they are mostly **pledged enterprises**, **tax-increment debt tools**, or **conduit financing**, not Tax Retirement Fund deposits.
