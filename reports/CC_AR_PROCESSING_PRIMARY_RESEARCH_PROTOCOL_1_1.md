## Purpose

Measure **usable** inspected processing capacity for Arkansas family livestock producers — not plant counts.

## Four layers (do not collapse)

1. **Nominal** — establishment exists  
2. **Accessible** — accepts independent producers  
3. **Available** — has booking space  
4. **Economically usable** — fees + haul + schedule + storage + market path still allow viable margin  

## Discrete verification

**Natural State Processing (Clinton)** status is a standalone packet. Do not contaminate cattle/hog conclusions with unresolved poultry directory conflicts.

## Priority plants

Pottsville Cypress Valley; 5R Mt. Vernon; Key's Van Buren; B&R Winslow; Hawthorn Hot Springs; state licensees (Ferguson, JACO, ASU, WBU); Clinton Cypress Valley (custom-exempt pathway only).

## Ethics

- Identify research purpose  
- Allow anonymity for sensitive fees/scheduling  
- Separate operator vs producer claims  
- Dual-source any hub-scale usage claim  
- Code refusals and non-responses honestly  
- **Never invent** wait times, prices, or interviews  

## Outputs

Inquiry log, booking matrix, economic usability worksheet, Natural State verification, updated access/gap matrices, return with Clinton finding preserved.
