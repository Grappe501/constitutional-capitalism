## Verdict

HYP-131 now thinks like an **Arkansas public-income system**, not a conventional tax-swap. Ten engines are architected with constitutional guardrails, purpose earmarks, and a hard count rule: **nothing counts until an evidence-backed cash-flow model exists.**

## Objective (locked)

Not: replace income tax with Tax X.  

Yes: move revenue away from taxing ordinary work and homeownership toward **use, impact, depletion, visitor demand, luxury discretion, human-capital dependence, value capture, enterprise returns, prosperity-fund compounding, and external income strategy**.

## TAX → FEE/RENT/ROYALTY → RETURN

| Form | Meaning |
|---|---|
| **TAX** | Compelled payment |
| **FEE / RENT / ROYALTY** | Pay because you use, deplete, or receive value from a public system/asset |
| **RETURN** | Arkansas earns because Arkansans own productive assets |

Direction: reduce TAX as rent/royalty and return grow.

## Constitutional guardrails

- **Import-Export Clause** and **Commerce Clause** bar discriminatory export/import duties and undue interstate burdens.  
- Rejected: food-export tax; energy export tax; state “defense import” tax.  
- Redirects: in-state value-chain capture; energy royalties/ownership/participation; federal defense as **External Income**.  
- Allowed: generally applicable taxes/use taxes with nexus; user fees tied to systems/costs; lawful public productive ownership.  
- Bound rate posture: state sales/use **6.5%**; state food **0%** (effective 2026-01-01).

## Bound anchors that matter

- Combined replacement map still ~**$3.859B IIT + ~$3.37B property ≈ $7.23B**.
